What the scan checks

  • Committed secrets — service_role JWTs and sb_secret_ keys in env files (rotating them comes first, always).
  • Policies open to everyone — USING (true) with TO anon, TO public, or no TO clause at all (the "the policy name says Users but it means anyone" trap).
  • Write-all policies — USING(true) WITH CHECK(true) for authenticated, where any logged-in user can rewrite any row.

What it doesn't check: live runtime configuration, private repos, edge functions, storage rules. This is a public-source surface scan — full audits go deeper. See methodology.
